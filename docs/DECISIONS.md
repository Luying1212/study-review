# 实现决策记录

## 2026-10-27 — 首版固定规则

| 决策 | 选择 | 理由 |
|---|---|---|
| 一般卡窗口 | 从 `firstEligibleOn` 起共 3 个学习日 | 计划 §4：短期回忆，不长期调度 |
| 自由回忆预算 | 最多占当晚预算 20%，按完整任务装入 | 计划 §5：避免挤掉到期核心卡 |
| 薄弱统计 | 最近 14 个学习日、≥3 个不同学习日首次正式「忘记」 | 计划 §4：按日计，补练/撤销不计 |
| 导入策略 | 完整替换；先校验、预览、备份、确认 | 计划 §3.6：第一版不做静默合并 |
| 版本分叉 | 停止自动覆盖，人工选择整侧 | 计划 §3.5：不做逐卡合并 |
| 仓库名 / Vite base | 环境变量 `VITE_BASE`，默认 `/study-review/` | 计划 §12；线上验收待仓库就绪 |
| 应用标识 `appId` | `study-review-workbench` | 拒绝误导入其他项目备份 |
| 校验器 | 自写 Node 校验，不引入 zod | 计划优先更少依赖 |
| 测试框架 | Vitest + jsdom | 计划 §1 |
| Node | 20（engines + CI 固定） | 与 Vite 6 兼容且受支持 |

后续变更 schema 或上述规则时，须同步校验器、构建、示例、导入导出与本文件。
